# My Portfolio Website

Personal portfolio website for my mid-semester project, made with HTML5, CSS3 and Bootstrap 5.

Live site: https://dwayne65.github.io/portfolio-website/

## Pages

- **Home** (`index.html`): intro, highlights, featured projects
- **About** (`about.html`): my background, experience, education, skills and hobbies
- **Gallery** (`gallery.html`): my motivation video and photo gallery
- **Contact** (`contact.html`): contact details, contact form and map

## Built with

- HTML5 and CSS3
- Bootstrap 5.3 and Bootstrap Icons
- A bit of JavaScript for the theme switch, gallery filter and form check
- Google Fonts (Inter, Space Grotesk)
- Some gallery photos are from Unsplash
